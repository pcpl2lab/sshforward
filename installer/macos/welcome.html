sshforward manages SSH local port forwarding tunnels as background processes.

This installer places a single command, sshforward, into /usr/local/bin, which is already on your PATH. The binary is universal and runs natively on both Intel and Apple Silicon.

It requires the OpenSSH client, which macOS already includes.

To remove it later, delete /usr/local/bin/sshforward.

If you use Homebrew, brew install pcpl2lab/tap/sshforward is the easier route and keeps itself updated.
